# 星枢 · 超分

给 Seedance 等 AI 生成的 720P 漫剧视频做**超分辨率 + 画质增强**，本地运行，针对 Apple 芯片 Mac（M1/M2，8GB 也能跑）优化。

- **AI 超分**：Real-ESRGAN（ncnn / Vulkan → Metal），720P → 1080P / 2K
- **画风一键切换**：仿真人 / 国漫 3D / 2D 动漫，自动套用合适的模型、强度和调色
- **AI 细节强度**：AI 结果与原画按比例混合，避免全强度带来的"AI 画"假感
- **一键调色**：原色 / 通透 / 鲜艳 / 电影感，强度可调；可加细微胶片颗粒
- **单帧预览**：正式处理前，拖动中线对比原片与成片
- **批量队列**：一次拖入多个视频或整个文件夹，按顺序处理
- **断点续跑**：分段处理，中途暂停、退出或断电后，从断点继续
- **省硬盘**：2K 临时帧处理完一段就删一段，1 分钟视频只需约 2–3 GB 临时空间
- **原音频保留**（统一为 48kHz AAC），Apple 硬件编码，可选 HEVC 或 H.264

## 安装与启动（macOS）

1. 安装 [Homebrew](https://brew.sh)（已安装可跳过）
2. 下载本仓库，双击 **`星枢超分.command`**
   - 首次运行会自动安装 ffmpeg、下载 Real-ESRGAN、创建 Python 环境，需要几分钟
   - 如果提示"无法打开，因为来自身份不明的开发者"：右键 → 打开，或在终端运行 `chmod +x 星枢超分.command setup.sh`

也可以手动安装：

```bash
./setup.sh
.venv/bin/python -m stellar_upscale          # 图形界面
```

## 推荐设置

先选"画风"，会自动套用下面的参数；之后手动调任何一项，画风会变成"自定义"。

| 画风 | 模式 | AI 细节强度 | 调色 | 颗粒 |
|---|---|---|---|---|
| 仿真人（默认） | 写实 | 60% | 通透 | 30% |
| 国漫 3D | 写实 | 80% | 鲜艳 80% | 10% |
| 2D 动漫 | 快速 | 100% | 鲜艳 70% | 0 |

这些是初版参数，会根据各类样片继续调整。其它情况：想要最快可选"快速"模式（写实画面强度控制在 40% 以内）；只想调色可选"无 AI"。

- **快速**模型（animevideov3）是为动画训练的，全强度会把皮肤磨平、给发丝描边，写实素材请把强度控制在 40% 以内
- **写实**模型（general-x4v3）用真实照片训练，不会把画面往二次元方向改；网络层数是快速模型的 2 倍，速度约慢 2 倍
- **精细**模型（x4plus）细节最多，但在 M2 8GB 上比快速模式慢约 30 倍
- 输出 1080P 时，内部也是先超分到 2K 再精细缩小（超采样），耗时与 2K 基本相同
- 要发到会二次压缩的平台，建议直接输出 2K；如果平台对 HEVC 处理不好，换成 H.264 再试
- 抖音等平台刚发布时通常只有 720P，高清晰度档位要等平台转码完成后才会出现

## 速度参考（M2 8GB 实测，720P 输入）

| 模式 | 每帧 | 10 秒视频（240 帧） | 1 分钟视频（1440 帧） |
|---|---|---|---|
| 无 AI | — | 几十秒 | 1–3 分钟 |
| 快速 | 约 0.9 秒 | 约 3.5 分钟 | 约 20–25 分钟 |
| 写实 | 约 1.5–2 秒（估算） | 约 6–8 分钟 | 约 35–50 分钟 |
| 精细 | 约 30 秒 | 约 2 小时 | 约 12 小时 |

快速模式的数据来自一次实测（提速优化之前）；写实模式按网络计算量推算；精细模式只跑了十几帧，是粗估。界面会显示实时进度和剩余时间，前几帧包含拆帧和加载模型的时间，剩余时间要处理十几帧后才稳定。处理时请尽量关闭其它大型程序，内存不足（开始使用交换内存）时速度会明显下降；精细模式若报错，可在命令行加 `--tile 256`。

## 命令行

```bash
.venv/bin/python -m stellar_upscale 视频1.mp4 视频2.mp4 \
  --style real -t 2k -o ~/Movies/超分
```

| 参数 | 说明 |
|---|---|
| `-t` | `1080p` / `2k` |
| `--style` | `real`（仿真人，默认）/ `cg3d`（国漫 3D）/ `anime2d`（2D 动漫），决定 `-m -s -p -g` 的默认值 |
| `-m` | `realesr-animevideov3`（快速）/ `realesr-general-x4v3`（写实）/ `realesrgan-x4plus`（精细）/ `lanczos`（无 AI） |
| `-s` | AI 细节强度 0–1 |
| `-p` | `original` / `clear` / `vivid` / `cinema` |
| `--preset-strength` | 调色强度 0–1.5 |
| `-g` | 胶片颗粒 0–1 |
| `-q` | `standard`（1080P 12Mbps / 2K 20Mbps）/ `high`（18 / 30Mbps） |
| `-c` | `hevc`（默认，体积小）/ `h264`（兼容性最好） |
| `--tile` | AI 分块大小，0 = 自动 |

按 Ctrl+C 中断后，重新运行同样的命令会从断点继续。

## 处理流程

```
原视频 ─拆帧(PNG)─┬─ 每 48 帧一段 ─ Real-ESRGAN ─┐
                 └──────── 原始帧 ───────────────┴─ 混合(AI 强度) → 调色 → 锐化 → 颗粒 → HEVC 编码
                                                    ↓
                               各段拼接 + 原音频 → 输出 xxx_星枢2K.mp4
```

## 文件位置

- 输出：默认与原视频同目录，文件名后缀 `_星枢2K` / `_星枢1080P`
- 任务记录与临时文件：`~/Library/Application Support/StellarUpscale/`

## 附带模型

`stellar_upscale/models/realesr-general-x4v3.*` 由官方 Real-ESRGAN 权重（BSD-3-Clause）用 `tools/convert_srvgg.py` 转换而来。
该脚本已用官方的 animevideov3 模型验证：转换结果与官方 ncnn 文件的权重差异不超过 1 个 fp16 舍入单位，超分输出 PSNR 65 dB。

```bash
python3 tools/convert_srvgg.py realesr-general-x4v3.pth stellar_upscale/models/realesr-general-x4v3
```
